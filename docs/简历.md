# 项目一 医药信息AI竞争情报搜集与RAG智能问答系统
针对医药行业公开资讯分散、竞品数据人工采集成本高、更新滞后，且采集情报无法快速检索答疑、利用率低等痛点，搭建自动化医药情报采集系统，新增向量存储与智能问答能力，实现情报抓取、结构化存储、向量入库、智能问答全链路闭环，为企业竞品分析、行业研判、情报快速咨询提供高效数据支撑。
**技术栈**：Python、Docker、Playwright、FastAPI、Langchain、Milvus、PostgreSQL、SSE、多线程、IP代理池
1. **多源站点爬虫搭建**：采用Scrapy框架结合Playwright动态渲染，适配静态官网、动态JS医药资讯平台，完成药企公告、药品审批、临床试验等多维度情报采集，覆盖20+医药行业数据源，保障情报覆盖面与时效性。
2. **反爬机制工程优化**：搭建代理IP池，结合随机请求头、请求间隔抖动、Cookie会话维持策略，以及退步重试策略，破解站点限流与封禁机制，将爬虫存活率提升至95%以上，保证长期稳定采集。
3. **数据降噪与双库存储设计**：设计多级清洗规则，通过正则匹配、重复哈希去重、空值过滤完成数据归一化；采用PostgreSQL存储业务结构化数据+Milvus向量库存储文本向量双库架构，兼顾业务查询与语义检索需求。
4. **情报RAG问答功能开发**：基于FastAPI搭建问答服务，对清洗后的医药情报进行语义分块与向量化处理，存入Milvus向量库；搭建检索增强问答链路，支持药企、药品、政策类情报智能问答，解决传统检索关键字匹配偏差问题。融合Milvus余弦相似度向量检索+BM25关键词检索双向召回，RRF融合排序后送入Cross-Encoder Reranker精排。
5. **流式交互体验优化**：基于SSE服务推送机制实现问答内容流式输出，实时返回大模型生成内容，优化人机交互体验；同时增加问答溯源功能，关联原始爬虫情报，保障医药问答内容真实可查。
6. **容器部署**：Docker Compose一键部署 FastAPI + Milvus + PostgreSQL服务，开发/生产环境隔离独立。

# 项目二 科研课题自动化审核系统(后端API)
传统医药科研课题审核依赖人工逐条校验，审核标准繁琐、主观性强、审核周期长，易出现错审漏审。基于大模型NLP技术搭建智能审核API，实现课题材料自动化合规校验与风险识别，节省项目成本100000元+。
1. **智能审核流程设计**：拆解49条课题审核业务规则，划分格式规范、项目基本面评估、内容方案评估、产出评估、申请人与经费评估六大审核维度，构建标准化审核流程，适配基金科研申报审核场景。
2. **大模型提示词工程优化**：采用Few-Shot示例约束模型输出，定制专属审核Prompt，规范评分标准与输出格式，降低大模型幻觉，审核结果准确率提升至95%。
3. **接口封装与服务部署**：封装高可用审核API接口，统一请求参数、异常捕获、超时重试机制，适配前端管理平台调用；优化大模型调用并发问题，超时重试保障大模型审核正常。
4. **PDF内容解析与规则引擎**：使用 pypdf 对上传课题 PDF 进行正文解析，结合 49 条固定评审规则对文本进行分段、截取与要点抽取，实现结构化语料输入的标准化处理。
5. **业务落地成果**：将人工审核时长由平均30分钟/篇缩短至30秒，大幅降低审核人力成本，实现审核标准统一、结果可溯源，完善科研项目基金申请审核体系。

# 项目三 基于Dify的企业内部智能知识库搭建
针对医药代表业务开展中，内部产品、管线、中标信息分散、查询效率低下的问题，基于Dify低代码AI平台快速搭建私有化智能知识库，无需大量底层开发，快速实现文档托管、智能检索、专业问答，满足企业内部知识沉淀与高效查询需求。
1. **差异化智能切分方案配置**：摒弃单一通用切分规则，依据文档类型定制切分策略；对CTR临床实验文档采用全文父子文段、对PDF、PPT等宣传文件采用父子分段切分、对宣传文档采用大粒度整块切分，搭配差异化重叠度参数；对于极度复杂文档，采用预处理流水线MinerU解析，统一转化为markdown形式入库。
2. **问答链路精细化配置**：定制专属提示词模板，约束模型输出规范；开启引用溯源功能，精准标注文档出处，规避大模型幻觉，保障专业问答内容严谨、可追溯。Dify后台自定义RAG检索策略，优化向量权重计算规则。
